**Car Data Analysis with Probability & Visualization**

This repository demonstrates how to analyze a small dataset of car attributes using Python libraries. The dataset includes Weight, Engine size, and Fuel consumption values stored in a dictionary and converted into a pandas DataFrame for structured analysis.

**The workflow covers:**
- **Data visualization:** Scatter plots of weight vs engine size using matplotlib.
- **Statistical analysis:** Calculation of mean and standard deviation for fuel consumption.
- **Normal distribution:** Using SciPy’s norm.pdf to plot a probability density function, showing how fuel consumption values are distributed.
- **Conditional probability:** Defining events A and B (fuel < 12, weight > 1500 & engine > 2.0) and calculating probabilities.
- **Bayes’ theorem:** Applying Bayes’ formula to compute P(A|B), demonstrating how conditional probabilities can be reversed.

This project combines data visualization, statistics, and probability theory to show how Python can be used for both exploratory analysis and mathematical reasoning. It is ideal for beginners learning how to integrate pandas, NumPy, matplotlib, and SciPy for practical data science tasks.

**Requirements**
To run this project, install the following libraries: 
pandas, numpy, matplotlib, scipy
